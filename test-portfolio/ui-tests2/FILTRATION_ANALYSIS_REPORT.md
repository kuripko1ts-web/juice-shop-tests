## Висновки

### Фільтрація

На сторінці пошуку Juice Shop **ВІДСУТНІ** видимі елементи UI для фільтрації продуктів. Це означає що:

- Немає кнопок для відкриття панелі фільтрів
- Немає категорій фільтрів
- Немає фільтрів за ціною
- Немає чекбоксів або радіокнопок для фільтрації

**Можливі причини:**

1. Фільтрація може бути реалізована через URL параметри
2. Фільтрація може бути прихована або доступна лише після певних дій
3. Фільтрація може бути відсутня в цій версії Juice Shop
4. Фільтрація може бути реалізована через API, а не через UI

### Сортування

На сторінці пошуку **ВІДСУТНІ** видимі елементи UI для сортування продуктів.

### Пагінація

Пагінація **ПРИСУТНЯ** і повністю функціональна:

- Можна змінювати кількість елементів на сторінці (5, 10, 15)
- Можна навігувати між сторінками
- Відображається діапазон сторінок
